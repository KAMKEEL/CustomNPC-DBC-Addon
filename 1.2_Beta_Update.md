# DBC Addon 1.2 Beta 1

Download: TBD

- **Form Stacking:**
> Custom forms can now stack with vanilla DBC forms (Kaioken, Ultra Instinct, God of Destruction, Mystic) with configurable multipliers. Also supports custom-to-custom form stacking with up to 4 pairs per form. Overrides for Legendary, Divine, and Majin multipliers.

- **DBC Ki Abilities (18 Total):** ⚠️ *This system may be retooled or remodeled -- expect changes to the data structure.*
> - **Blasts** - Ki Blast, Big Bang Attack, Burning Attack, Death Ball, Spirit Bomb, Large Spirit Bomb, Super Spirit Bomb, Supernova
> - **Beams** - Ki Wave, Double Sunday, Kamehameha, Masenko, Galick Gun, Final Flash
> - **Laser** - Special Beam Cannon
> - **Discs** - Destructo Disc, Death Saucer

- **DBC Damage on Abilities:**
> Abilities now use full DBC damage calculations. Per-ability DBC stats: Friendly Fist, Ignore Dex, Ignore Block, Ignore Endurance, Ignore Ki Protection, Ignore Form Reduction, and Defense Penetration (0-100%). Configurable via a dedicated DBC Stats tab in the ability editor.

- **Overlay System Overhaul:**
> Complete rebuild of the overlay rendering system. New Overlay Chain architecture with conditional rendering, per-body-part targeting (Face, Eyes, Mouth, Chest, Arms, Legs), dynamic color sources, and named chain organization. Includes built-in overlays for Pupils, SSJ3/SSJ4 Faces, SSJ4 Fur, Oozaru, Savior, Black Frieza, and Namekian textures.

- **Overlay Scripts:**
> Janino-compiled Java-like scripts for dynamic overlays. `getTexture(ctx)` and `getColor(ctx)` functions with full access to entity state, race, gender, form, and color data. Per-overlay script support.

- **Overlay GUI Renovation:**
> Rebuilt overlay editor with improved layout, scrolling, type selection, face part control, and integrated script editor.

- **DBC Settings API:**
> Scripting API for toggling DBC player settings: Fusion, Mystic, Kaioken, UI, GoD, Friendly Fist, Swoop, Ki Protection, Ki Fist, Ki Weapon, and Instant Transmission range.

- **DBC Skills Enum:**
> Type-safe enum for all 19 DBC skills with TP/Mind cost calculation methods. Replaces string-based skill lookups.

- **Built-in DBC Animations:**
> Pre-packaged animations (Namek Regen) that ship with the addon without using world directory space.

**Bug Fixes**

- Fixed form checking order for secondary form stacking.
- Fixed ki drain on transform and improved ki drain logic for form mastery.
- Fixed GL resource leak in rendering.
- Fixed outline render bugs.
- Fixed broken SubGui components.
- Fixed server shop display issues.
- Fixed Savior from Heaven and SSJ4/SSJ3 face rendering.
- Fixed Form GUI not saving on escape close.
- Fixed pupil rendering for SSJ3.
- Fixed body overlay blending and alpha states.
