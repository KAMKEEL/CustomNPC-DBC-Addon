# ⚡ DBC Addon 1.2 - Abilities & Overlays ⚡

---

The **1.2 Update** is the biggest DBC Addon release yet! Custom forms can now **stack** with vanilla DBC forms, NPCs can unleash **18 unique ki-based abilities** with full DBC damage integration, and the entire **Overlay system** has been rebuilt from the ground up with scripting support!

---

## Form Stacking 🔄

Custom forms can now **stack with vanilla DBC transformations** and with other custom forms!

### Vanilla Form Stacking

Each custom form can be configured to stack with any combination of vanilla DBC forms:

- **Kaioken** - Stack with Kaioken at configurable levels and multipliers
- **Ultra Instinct** - Stack with UI and set a custom multiplier
- **God of Destruction** - Stack with GoD form
- **Mystic / Potential Unleashed** - Stack with Old Kai Unlock

Additionally, custom forms can **override the default multipliers** for Legendary, Divine, and Majin forms when stacking.

### Custom Form Stacking

Custom forms can also stack with **other custom forms** using the Custom Stackable system. Each form supports up to **4 custom stacking pairs**, linking two forms together for complex multi-form transformation chains.

> Circular dependencies and parent/child conflicts are automatically prevented.

## DBC Damage on Abilities 🎯

Abilities now support **full DBC damage calculations** instead of vanilla Minecraft damage. A new damage handler intercepts ability hits and routes them through the DBC combat system.

### Per-Ability DBC Stats

Every ability has its own configurable DBC combat stats:

- **Friendly Fist** - Prevent lethal damage for a duration
- **Ignore Dex** - Bypass dexterity-based dodge rolls
- **Ignore Block** - Bypass block damage reduction
- **Ignore Endurance** - Bypass endurance-based resistance
- **Ignore Ki Protection** - Bypass ki protection shields
- **Ignore Form Reduction** - Bypass form-based damage reduction
- **Defense Penetration** - 0-100% armor penetration

### GUI Integration

A dedicated **DBC Stats tab** appears in the ability editor for any ability that deals damage. All DBC stats are configured per-ability and saved in the ability's custom data.

> DBC damage stats are also accessible through the scripting API via `getAbilityDBCStats()`.

## Overlay System Overhaul 🎨

The entire overlay rendering system has been **completely rebuilt** with a new architecture for maximum flexibility.

### Overlay Chains

Overlays are now organized into **Overlay Chains** -- named groups of overlays that render together with shared conditions.

- **Conditional Rendering** - Chains activate based on form state, race, gender, or custom predicates
- **Face Part Control** - Chains can disable specific face parts (eyebrows, eyes, nose, mouth)
- **Named Organization** - Chains are named for easy identification and management

### Overlay Types

Overlays can now target **specific body parts** for precise rendering:

**Face Parts:** Face, Eyebrows, Eye Whites, Left Eye, Right Eye, Nose, Mouth
**Body Parts:** Chest, Arms, Legs, or ALL

### Dynamic Color Sources

Overlays can pull colors dynamically from the character:

- Custom Color, Eye Color, Hair Color, Fur Color
- Body Colors (CM, C1, C2, C3) for Arcosian forms

### Built-in DBC Overlays

Pre-configured overlay chains ship with the addon:

- **Pupils** - Race-specific pupil rendering for all races and body types
- **SSJ3 Face** - Custom face with hidden eyebrows and unique eye whites
- **SSJ4 Face** - Fur-colored eyebrows with custom eye rendering
- **SSJ4 Fur** - Full body fur texture overlay
- **Oozaru Fur** - Great Ape fur overlay
- **Savior from Heaven** - Fur and glowing effect overlays
- **Black Frieza** - Body textures for all Arcosian body types
- **Namekian Overlays** - Race-specific Namekian textures

### Overlay GUI

The overlay editor GUI received a **major renovation** with improved layout, scrolling, type selection, and an integrated script editor.

## Overlay Scripts 📜

A brand new scripting system for overlays using **Janino** (Java-like) compiled scripts.

- **Dynamic Textures** - `getTexture(ctx)` returns texture paths based on entity state
- **Dynamic Colors** - `getColor(ctx)` returns colors based on entity state
- **Rich Context** - Scripts have access to the full `OverlayContext`: entity data, race, gender, age, body type, current form, eye/hair/fur colors, and more
- **Per-Overlay Scripts** - Each overlay can have its own script for independent logic

> Overlay scripts compile at edit time and execute every render frame for real-time dynamic overlays.

## TypeScript API Definitions 📄

Auto-generated **`.d.ts` TypeScript definition files** for scripting autocomplete and type checking.

- Covers all DBC Addon API interfaces (Forms, Overlays, Settings, Events, Auras, Outlines)
- Patches existing CNPC+ APIs (e.g., `IPlayer.getDBCPlayer()` returns `IDBCAddon`)
- Generated automatically during the build process
